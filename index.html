Box Model, Display y Posicionamiento

1. Box Model

Todo elemento HTML puede entenderse como una caja. El Box Model está formado por contenido, padding, border y margin.

Contenido width: 250px

padding: 30px
border: 8px

Partes del Box Model

  • Content: contenido del elemento.
  • Padding: espacio entre el contenido y el borde.
  • Border: borde de la caja.
  • Margin: espacio exterior de la caja.

box-sizing

En esta página utilizamos box-sizing: border-box. Esto hace que el ancho y alto definidos incluyan el padding y el border.

.caja-modelo {
  width: 250px;
  padding: 30px;
  border: 8px solid blue;
  box-sizing: border-box;
}

2. Elementos Block e Inline

La propiedad display determina cómo se comporta un elemento dentro de la página.

Elementos Block

Los elementos block ocupan todo el ancho disponible y comienzan en una nueva línea.

Soy un elemento BLOCK
Yo también soy BLOCK

Elementos Inline

Los elementos inline ocupan solamente el espacio necesario y pueden aparecer en la misma línea.

Texto normal: INLINE 1 INLINE 2 INLINE 3
.block {
  display: block;
}

.inline {
  display: inline;
}

Float y Clear

La propiedad float permite que un elemento se desplace hacia la izquierda o derecha, mientras que el contenido puede colocarse a su alrededor.

FLOAT

Este texto se coloca alrededor de la caja porque la caja tiene aplicado float: left. Esto significa que el elemento se desplaza hacia la izquierda y el contenido que viene después puede ocupar el espacio disponible a su lado.

Podemos escribir más contenido para que se vea claramente cómo el texto continúa alrededor del elemento flotante. Cuando el espacio lateral termina, el texto continúa debajo de la caja.

CLEAR
Este elemento utiliza clear: both, por lo que ya no se coloca junto al elemento flotante.

Propiedades utilizadas

.caja-float {
  float: left;
}

.clear {
  clear: both;
}

3. Position: Relative y Absolute

La propiedad position permite controlar la posición de un elemento.

Contenedor: position: relative

Este contenedor sirve como referencia para el elemento absolute.

RELATIVE
top: 20px
left: 20px
ABSOLUTE
top: 20px
right: 20px

¿Qué diferencia hay?

Relative

Se mueve desde su posición original, pero conserva el espacio que ocupaba.

Absolute

Sale del flujo normal y se posiciona respecto a un contenedor de referencia.

4. Position: Fixed

Un elemento con position: fixed queda fijado respecto a la ventana del navegador.

Para comprobarlo, desplázate hacia abajo. El botón verde de la esquina permanecerá en la misma posición.

.elemento-fixed {
  position: fixed;
  bottom: 20px;
  right: 20px;
}

5. Comparación de Position

Relative

Se mueve desde su posición original.

position: relative;

Absolute

Se posiciona respecto a un contenedor de referencia.

position: absolute;

Fixed

Permanece fijo respecto a la ventana del navegador.

position: fixed;
